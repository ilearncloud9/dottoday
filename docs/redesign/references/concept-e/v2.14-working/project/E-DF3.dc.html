Focus order, wide Minimal (Mac and web)
  • Tab order: 1 sidebar → 2 toolbar → 3 horizon → 4 Now actions (Done, Focus, Need more time?) → 5 Also now / Next, the Add a task field and Hide the Day column → 6 Day column (header, then its rows). On web the built “Skip to content” link comes first.
  • 3 · Horizon: one Tab stop. ← / → move from dot to dot, Home / End go to the first or last, Return or Space opens the task in the Day column. Each dot speaks its own name (“Lunch, 12:30 to 1:15 PM”).
  • 6 · Day column: ↑ / ↓ move between rows; Return opens; the Earlier and before-Wake-Up rows toggle with Space or Return (ED-246).
  • 7 · Task open: focus moves to the task’s title in the Day column. Tab stays inside the task screen’s controls, then continues to the sidebar. Esc or ✕ closes it and focus returns to the dot or row that opened it. Day review behaves the same.
  • Narrow windows: the Day panel returns focus to its “Day” button (ED-170, unchanged).
  • Full (Workspace): as on E-G4-7-States D2 — sidebar → toolbar → Plan panel → week → inspector.
  • Phones: VoiceOver and TalkBack follow reading order; the horizon is one adjustable element (swipe up / down moves dot to dot) with a custom action “Open”.

B · The Week for screen readers (CR-107)

The Week for screen readers (Full, Mac and web)
  • The week reads day by day, not as a grid (built: each day is a heading, then its cards). Proposed: each day heading also says how full it is — “Tuesday 3, today, 9 tasks, 7 hours 40 planned”.
  • Cards read in start order; overlapping cards read in start order and say “overlaps Call with Sam”.
  • VoiceOver rotor / headings: jump day to day. Keyboard (proposed): Tab enters the week on today’s first card; ↑ / ↓ move within a day, ← / → to the same time on the next or previous day; Return opens the inspector.
  • No second “list view” is added: the same screen reads as a list.

C · Reduce Transparency and Increase Contrast (rest of CR-103)

Reduce Transparency and Increase Contrast, every board
  • Adopts E-G4-7-States D4 as the rule for every active board instead of redrawing each one: glass becomes solid with a 1.5 px outline; secondary text one step darker; the dotted thread stronger.
  • iPhone: Liquid Glass tab bar, + and Day ▾ turn solid (iOS 26 and the 16–18 fallback). Android: the frosted toolbar turns solid when blur is off. Mac: sidebar vibrancy falls back to solid. Web: already solid.
  • Increase Contrast: borders and focus rings at 3:1 or more on every surface; no information carried by translucency alone.

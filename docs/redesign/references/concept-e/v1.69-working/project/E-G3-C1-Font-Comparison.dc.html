G3-C1 · Task text font on Android · cleanup 7a and 7b · comparison for review (not applied)

ED-110 put task content in Manrope; ED-112 asked to see a comparison before changing text in phone sheets (G3-C1). Each pair uses the same real frame, text and width; only the field's font changes. Keyboard, selection, cursor, validation and accessibility are the platform's in both. Phones at 60 %.

7a · Add input · recommendation: Manrope 600 20 on Android too
Correction: the earlier "iPhone system 500 19" and "Android Roboto 500 20" readings were time labels (a Create task time tile and the Edit Weekdays times), not Add inputs. The only Add inputs left are Minimal: iPhone Manrope 600 20, Android Manrope 600 19. So 7a is 19 → 20 on Android Minimal.
Measured: both stay one line (single-line field, long text scrolls inside it). Normal and 130 % fit the 56 px field. At 200 % the 40 px text is 57 px tall in a 56 px drawn field; the 38 px current text is 54 px. In the app the native field grows with the text, so neither clips; the drawing does not reflow the sheet.
Why 20: same family and weight already; +1 px makes iPhone and Android identical and is barely visible. Keeping 19 would keep a difference with no platform reason.
7b · Android task title · recommendation: Manrope 700 24/30, as on iPhone
Identity: task names are Manrope everywhere else (timeline, iPhone editor, Minimal); the Android editor is the only place a task name turns into Roboto. Manrope makes it the same task on both phones. The app bar ("Edit task", "New task") stays native Roboto, so title vs chrome stays distinct.
Measured cost: Manrope 700 24 is wider and taller: the long title wraps to 4 lines instead of 3 at normal size, 5 instead of 3 at 130 %, 8 instead of 6 at 200 %. Short titles grow 5–7 px. On Edit task the editor scrolls, so nothing is lost.
Found at 200 % on Create task: with the keyboard up, the header above the keyboard holds about 6 lines. Roboto (6 lines) fits; Manrope (8 lines) runs past it and is cut off in this drawing. Adopting Manrope needs the title field to scroll inside the header with the cursor kept in view (native text-field behaviour), or the header to grow and push content up. The same requirement applies to iPhone, which already uses Manrope 700 24.
Alternatives: Manrope 700 at 22/28 (brand font at Android's current size, less wrapping) or keep Roboto 500 22 (no change).
Also found (not 7b, unchanged): the Android Minimal edit title is Manrope 800 21. Logged for a later decision.

E-PhonesMinimal frame 6 (M3 modal bottom sheet). Single-line field: long text scrolls inside the field (native), it never wraps. iPhone Minimal Add is already Manrope 600 20 (reference below). Only the field text is scaled at 130 % and 200 %; the sheet itself is not reflowed here (its 200 % layout belongs to the platform).

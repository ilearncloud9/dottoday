How the keyboard is dismissed
  • Swipe down on the sheet or drag its content: the keyboard hides first; the sheet stays and the text stays. A second swipe closes the sheet as before.
  • Tap outside the field on the sheet (title, empty space): the keyboard hides; the draft stays.
  • Return creates the task (or adds the next step); Create task closes after creating.
  • Cancel / Close / Done close the sheet as already approved; nothing new.
  • VoiceOver: the two-finger scrub gesture hides the keyboard like a swipe. Hardware keyboard: no on-screen keyboard; Esc leaves the field.
  • Android: Back (or predictive Back) hides the keyboard first, then closes the sheet.
  • Tapping the field again brings the keyboard back with the caret at the end of the same text.

Rules
Same Add everywhere
The Mac and web popover holds the phone Add: modes, live chips, summary, duration, Inbox.
Chips are reversible
A parsed word is a chip with ×; removing it keeps the word as text.
Overlaps inform
An overlap is a note you can ignore, never a block and never red.
One month component
Go to date reuses the approved month grid and its dots (ED-075).
Keyboard first
⌘N, n, ⇧⌘G and arrow keys reach everything; Esc always closes.
Text from the app
Every string is built or from an approved board. Tasks and dates are examples. No new copy.

What option B means

First screen
Today's thread, the same first screen as phones. More room for the day itself; the inspector opens on click.
Current task and Focus
The now card on the thread, with Focus on it. The same rule as phones in Full.
Planning
One click away: the Calendar row opens the Workspace grid with the Inbox column. Today has no Inbox column; Inbox is its own row.
Same app as the phone?
Yes: one drawing of today everywhere. The grid is an extra view on wide screens, like Week where the width allows (Q5).
Cost and risk
More to draw: the wide Today at 1280 and 960 and dark mode. Two views of today (thread and Calendar) read the same data, so they must stay in step.

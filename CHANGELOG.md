# Changelog

All notable changes to this project will be documented in this file (Keep a Changelog, SemVer).

## [Unreleased]

### Added
- Project kit: agent instructions, specs, schema, implementation plan.
- **Milestone 1 complete** (M1.9): `/ship-check` passed 2026-10-21 locally — analyze/format clean, 389 tests, `lib/domain` coverage 98.3 % (overall 92.9 %), all four targets build (web, Android debug, macOS debug, iOS simulator); GitHub Actions could not run (account billing), so CI re-run is a follow-up.
- **Milestone 0 complete** (M0.10): `/ship-check` passed 2026-10-21 — analyze/format clean, 111 tests, 83.2 % coverage (hand-written), 23 pgTAP RLS tests, all four targets build in CI, a11y guidelines + axe-core clean, gitleaks/osv-scanner clean.
- M0.1: Flutter project scaffold (iOS, Android, macOS, Web) with blank shell app, smoke test, Inter font, placeholder assets and committed `pubspec.lock`; `intl` bumped to ^0.20.3 and `analyzer` pinned <7.4 so codegen compiles.
- M0.2: Feature-first folder layout (`core`, `data`, `domain`, `features/*`, `shared`, `integration_test`) with boundary READMEs.
- M0.3: `core/env` — `Env` loaded from `app/.env` in `bootstrap()`, provided via `envProvider`; fails fast on missing/invalid `SUPABASE_URL`/`SUPABASE_ANON_KEY` and rejects service-role keys.
- M0.4: `core/theme` — semantic colour, type (Inter), spacing, radii and motion tokens from 03 §1 via `AppTheme.of(context)`; zero-duration motion under reduced motion; light/dark goldens. Removed unused `google_fonts`.
- M0.5: `core/router` — go_router with the 8 routes (5-branch shell + `/day/:date`, `/month`, `/task/:id`); every location passes an allow-list guard (real dates, UUID v7 IDs, no query/fragment/foreign scheme) and falls back to `/today`. Plan: add M0.13, M5.0, M4.2 ownership note.
- M0.6: `core/l10n` — gen-l10n (en source, `nullable-getter: false`), `context.l10n`, localised app title; policy tests forbidding UI string literals (all of `features/**` and `shared/**`) and cross-layer imports (feature→feature, domain→Flutter, shared/core→features).
- M0.7: `core/clock` (`Clock`, `SystemClock`, test `FakeClock`), PII-safe structured `Logger` (event keys only, typed fields, `LogId`/`Logger.redact`, errors by type) with `no_pii_in_logs` policy test, sealed `AppFailure` (enum-only fields) with localised messages, and hand-rolled `Result<T, F extends AppFailure>`.
- M0.8: GitHub Actions — `app` (codegen freshness, format, analyze, tests; goldens on macOS with 0.1 % tolerance), `supabase` (pgTAP RLS), `security` (gitleaks, osv-scanner); all actions SHA-pinned.
- M0.9: Migration `0002_sync_push_fixes` — subtask sync works (was always failing), subtasks can only reference own occurrences, clear unknown-field errors, HLC format + 5-min future bound (ADR-0002 amended); 16 new pgTAP tests. Remote push deferred to M6.0.
- M0.11: Toolchain on Riverpod 3 + native `riverpod_lint` (custom_lint and analyzer pin removed; CI uses `dart analyze`); root `ProviderScope` disables auto-retry; uncaught errors logged with `ProviderException` unwrapped; remaining packages bumped to latest majors, blocked ones pinned with reasons.
- M0.12: Config compiled in via `--dart-define-from-file` (ADR-0005); no `.env` in any bundle; missing define names the exact command. CI builds all four targets (Apple on Xcode 26.5); fixed Android desugaring/minSdk 26, iOS min 16, and removed `drift_flutter` (broke Apple builds since M0.1).
- M0.13: App shell — adaptive bottom bar (< 600 dp) / SafeArea rail (≥ 600 dp) with l10n labels, Quick Add FAB with list clearance, single `AppShortcuts` table (⌘/Ctrl+1–4, ⌘/Ctrl+N) bound above all routes.
- M0.14: Accessibility gates — one-line `expectA11yGuidelines(tester)` (≥ 44 pt token, 48 dp, labelled targets, WCAG contrast) run on the shell in light/dark × compact/expanded; axe-core scan of the web build in CI (0 violations); `/review` blocks screens without the helper.
- M1.0: Block palette — 12 colours (coral … slate) with light/dark `base`/`strong` in `assets/design/palette.json`, generated to `block_palette.gen.dart` by `tool/gen_block_palette.dart`; `BlockColor.fromKey` falls back to indigo; exposed as `AppTheme.of(context).blocks`. Tests: strong ≥ 3:1 on surface and ≥ 4.5:1 on its block fill, generator freshness + malformed-input rejection.
- M1.1: Domain entities (freezed + JSON, snake_case rows, UTC epoch ms): `Series`, `Occurrence`, `Subtask`, `Alert`, `SubtaskTemplateItem`, `CalendarAccount`, `CalendarLink`, `Profile`, `Settings`; validators per 05 "Validation" returning `Result<T, ValidationFailure>`; pure `block_color_keys.gen.dart` from the palette generator; tz database loaded in `bootstrap()`.
- M1.2: `RecurrenceExpander` — expands a series to UTC starts in a window on its own wall clock (DST gap → shifted forward, overlap → first instant), RFC 5545 COUNT/UNTIL/EXDATE semantics, UTC vs floating vs date-only `UNTIL`; `wallClockToUtc`/`utcToWallClock` helpers; sub-hourly rules rejected by validation.
- M1.3: `Materialiser` — plans the missing occurrence rows for a series over `[now − 1 day, now + 90 days)`; idempotent (existing rows incl. edited/skipped/tombstoned are exceptions); fresh per-occurrence subtasks from the template (R-09); `IdGenerator` (UUID v7) in `core/ids`.
- M1.4: `DaySchedulerService` — `shiftFollowers` (gaps preserved, calendar excluded by default, stops at pins and never pushes a block onto/across one), `runningLate` (planned blocks from now, up to the first pin), `insert` (`overlap`/`bump`/`fitNextGap` with travel buffers), `suggestSlots` (grid-snapped free gaps); `ShiftReport` for partial-shift toasts; seeded property tests.
- M1.5: `QuickAddParser` (en, de, fr, es) — times (7am, 19:00, noon, 15 Uhr, 15h30), relative days and weekdays, durations (45m, 1.5h, 2 Stunden), recurrence prefill ("every mon,wed", "jeden Tag", "tous les jours", "cada día"), `@inbox`; token spans for removable chips; multi-line paste with bullet stripping (R-06, R-07, R-20).
- M1.6: `NotificationPlanner` — desired pending set for the next 7 days from occurrences × alerts (series inheritance, before/at start/at end/overdue), stable 31-bit IDs from `occurrenceId#alertIndex` with collision probing, silent delivery in quiet hours, snooze reminder, iOS 64-limit windowing, and `diff` against the OS pending set (cancel + schedule) (R-10).
- M1.7: `Hlc` (fixed-width wire format, string order = clock order) and `HybridLogicalClock` (monotonic `now`/`receive`, counter-overflow borrow, 5-min drift guard); `ConflictResolver` — per-field LWW, same-field edits within 60 s become a `Conflict` that keeps the server value (ADR-0002, R-08).
- M1.8: Export/import model — `ExportBundle` JSON v1 encode/decode with validated import (size ≤ 25 MB, version, schema, entity rules, duplicate ids, references, single owner) and `reownedTo`; CSV per entity (RFC 4180, formula-injection escape); ICS writer (series as TZID+RRULE with EXDATE/RECURRENCE-ID, folding, escaping); hostile-fixture round-trip tests (R-11).
- M2.0: Dart SDK floor `^3.8.0` (Flutter ≥ 3.32); repo reformatted to the tall style and generated code regenerated; null-aware elements and wildcard `_` adopted where lints asked.

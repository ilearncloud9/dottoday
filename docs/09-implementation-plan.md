# 09 — Implementation Plan

The agent works top to bottom. A milestone is done only when every task is `[x]` and `/ship-check`
passes. Each task lists the spec sections and `R-xx` IDs it must satisfy. Keep tasks small; split a
task rather than leaving it half-done. Add new tasks here when discovered — never keep them in your head.

Legend: `[ ]` todo · `[x]` done · `[~]` in progress (only one at a time).

Standing rule from M8.3 on (every later task, M9–M12 included): a new or changed user-facing string
ships in **en, de, fr and es in the same commit** — `test/policy/l10n_parity_test.dart` fails CI on a
missing, extra or untranslated key, a dropped placeholder or a changed select case. Follow the copy
rules and glossary in `03-ux-spec.md` §5. After any ARB change run
`dart run test/support/pseudo/write_pseudo.dart` (from `app/`; a test says when it is stale), and add
every new screen to `test/core/l10n/locale_sweep_test.dart` (pseudo-locale at three widths + de/fr/es).

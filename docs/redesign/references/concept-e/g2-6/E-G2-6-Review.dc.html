How the four screens follow your requirements

  • E-Minimal identity kept: the Mac and web frames are E-Minimal's own windows; only the task column's content changed. Its header (Task · ✕), dot, title, "Now, 18 min left", Starts and Duration fields (with − / +) and the More button are E-Minimal's markup.
  • Done prominent: one full-width teal button, first.
  • Tomorrow and Later easy to find: two equal buttons right under Done, with icons.
  • Need more time? only on the running task, as on Now.
  • Delete secondary and protected: a small grey text button at the bottom, separated from the actions by More options; it moves the task to Trash with Undo (built rule). No colour, no tile.
  • No Colour and icon on screen: the dot is not a button here; colour and icon are in More options.
  • More options: opens the option D editor for the same task and date; any typed Starts or Duration change is already saved, so nothing is lost. Esc or Done in the editor returns to this screen.
  • Phones: E-PhonesMinimal's Today (iPhone) and Now (Android) behind a native sheet (iOS medium detent; M3 partial sheet). Targets 44 pt / 48 dp.
  • Mac and web: 274 pt column on Mac, 468 px on web; no clipping, buttons 40–44 high. Keyboard: ↩ Done, T Tomorrow, L Later, ⌘⌫ Delete (shortcuts are G2-10, shown as a proposal).

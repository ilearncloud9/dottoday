G4-5 · Mobile web (approved, ED-172)
Layout: the 600 / 840 classes and H1 apply as everywhere. Compact web gets its own bottom bar: solid surface, hairline, labelled icons, web focus ring. It never imitates the iOS glass bar or the Android frosted toolbar. Full keeps Today · Inbox · Calendar · Search; Minimal keeps Now · Today · Inbox. Add, Brain dump, Routine, editing and every task action stay available. Not reduced to Today.
Routes (unchanged, G2-11 / ED-097): hash URLs /#/now, /#/today, /#/day/:date, /#/inbox, /#/search, <view>?task=<id> by rule T, at phone width the phone column. Back, Forward and refresh restore view, date and task; one Back step per view, date or task you open; redirects and resizes replace the entry. Sign-in guards and unsaved-edit safeguards stay. No new routes.
Gestures: no custom edge-swipe; the browser's own Back gesture works as usual.
Web interactions: web menus, dialogs and sheets; safe areas, browser bars and the keyboard respected (the visual viewport); the bottom bar never covers fields, Add or task actions; touch, keyboard and screen readers. Single-key shortcuts (n add, / search …) keep their off switch (WCAG 2.1.4); task state and unsaved text survive reflow.
Wider browser windows: 600–839 is medium and ≥ 840 expanded, the same as desktop web (E-Responsive). Tablets' browsers follow G4-4; drawn in Round 2.
Real E-Phones and E-PhonesMinimal content inside browser chrome. Browser behaviour (Back/Forward, refresh, keyboard, safe areas, screen readers): PENDING testing.

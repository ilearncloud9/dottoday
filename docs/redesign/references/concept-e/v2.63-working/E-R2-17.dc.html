Rules for every surface
One snapshot, five intents
Every surface reads DaySnapshot and runs only the five App Intents (Add task, Mark done, +15 min, Start focus, Open). None talks to Supabase (CLAUDE.md §11).
The thread and the dot
Now is a ring in the task colour that fills with time used; ahead is a hollow dot; done is filled. The day dot fills from Wake Up to Wind Down.
Text from the app
Every word arrives formatted and translated in the snapshot (Now, Next up, until {time}, Done, +15 min, {n} in Inbox). No new strings on this board.
Calm by default
No badges for overdue, no red, no streaks. The ongoing notification is silent and alerts once; the Live Activity ends with the task.
Native chrome
Each surface keeps its system shape: WidgetKit corners and families, Glance sizes, the Dynamic Island, Quick Settings tiles, the macOS menu.
No new targets
Everything drawn exists today. A watch app, Mac widgets or a Wake Up Live Activity redesign would be new targets and need the owner first.

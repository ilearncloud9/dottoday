What changes in Full

  • Phones: five groups → four (Time · Plan · Day · Layout). Running late → Need more time ▸ (G1). Rebalance… added. Copy day as text moves into Day; Review and This week join it.
  • Mac and web: E-FullA-v2 stays; Routines… is named Drop a routine… (as in G2-8's File menu); Plan / Reality joins Layout.
  • Replan button: none. Its actions are the Time group; Need more time is also on the Now card and the task screen.
  • Any day: Plan, Day and Layout work on any viewed day; Time is today-only and shows disabled on other days (as E-FullA-v2 draws).
  • Kept: Brain dump and Drop a routine stay here as well as in Add (G2-8).

Why B is recommended

  • It is your latest design (ED-076): E-Minimal's band says minimal hides, never removes, and points to the Day menu for the hidden actions.
  • Mac convention: the menu bar lists every command so keyboard and VoiceOver users can reach them; trimming it would leave only ⌘K.
  • Phones stay calm: doc 14's short header menu is kept where the screen is small.
  • Cost: doc 14 §4 needs a line saying the three-item cap is for phone headers; wide minimal uses the Day menu.
  • Option C (a separate Replan / Running late button in Full on Mac and web, as the built spread and E-Workspace have) is not drawn: two controls for one job.

Also settled with this decision (all options)

  • One increment set: +5 / +15 / +30 everywhere (built).
  • Need more time behaves like the built Running late: extend the task now, then optionally shift the rest.
  • One name for low energy: Low-energy mode (built string). Low-energy day and Gentle Day go.
  • One name for routines here: Drop a routine… (Routines… opens the Routines page from the sidebar and Settings).
  • Show less / Show everything is always in the Day menu (G1-4).

Tablet implications (recorded, not drawn)

  • iPad: the Day ▾ pull-down at every width; with a hardware keyboard the same groups appear in the iPadOS menu bar (as on Mac). Pointer hover and ↑↓ in the menu.
  • Android tablets and foldables: the M3 menu anchors to the Day button in the top app bar in every window size; in expanded two-pane it stays with the day pane, not the rail.
  • Wide minimal on tablets: follows the phones' short menu unless Round 2 decides tablets use the wide minimal layout.
  • Unverified: iPadOS menu-bar contents per window size; Android keyboard shortcut helper. Round 2: draw in the tablet checklist pass.

Recommendation: C

  • Calm where it is constant: the pointer passes over blocks all the time; C's hover is a tint, so the grid stays flat and quiet.
  • Clear where it matters: a dragged block lifts above Deep work and Call with Sam, as in A, so overlaps stay readable.
  • Strictest reading of the lean finish: a shadow appears only on a block that is really lifted off the grid.
  • Cost: the hover tint #F5F1EB is a new value (a proposal, from 4 % ink on the block); the drag lift reuses A's shadow. Motion (lift timing, scale) stays open in §7.5.
  • Not merged: if you choose C, Lunch's hover look on E-FullA-v2 changes to the tint, and the drag look is recorded in the rules.

Platforms and tablets

  • Web: as chosen. Mac: the same Workspace grid with a pointer, so the same rule.
  • iPad and Android tablets: with a pointer or trackpad, the same hover rule; dragging by touch uses the drag look (Round 2).
  • Phones: no hover; the drag lift belongs to the motion spec.

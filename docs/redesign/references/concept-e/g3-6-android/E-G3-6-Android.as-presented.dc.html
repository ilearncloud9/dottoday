Recommendation: A

  • Native for Android: the + floating above an edge-to-edge navigation bar is the Material 3 pattern Android users know.
  • Your change still applies: “Add” becomes the + on every Android screen, as on Minimal already.
  • B reproduces the iPhone arrangement but uses no Material component and squeezes the navigation items.
  • C looks closest to the iPhone, but Material 3 Expressive intends the floating toolbar for actions; using it as the main navigation is a deviation.

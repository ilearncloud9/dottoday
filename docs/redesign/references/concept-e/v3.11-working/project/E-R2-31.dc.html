Rules
Window, not device
Every tablet case is a width class of the window: Stage Manager, Split View, foldables and browsers all follow compact, medium and expanded.
One toast
The R2-7 toast, centred on the content area at medium and expanded; never under a rail or a sidebar.
Hinge: code needed
The app reads no display features yet; the approved rule (no pane or text across a hinge) needs a code task.
Browsers
Tablet browsers get the same layouts as the native app at the same width (ED-172).
Nothing lost
Resizing a window or folding a phone keeps the open task, the scroll and any draft.
Text from the app
Every string is built. Tasks and dates are examples. No new copy.

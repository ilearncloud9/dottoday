Rule across surfaces
Built Now → Next up → Nothing else today: one rule on widgets, the menu bar and (by design) the Now view
Rule An ended task is never called late, missed or overdue on screen; it is “not done” until you tick it or move it
Rules
No shame
“· not done”, never late, missed or red. The nudge asks “Need more time?” once, and Not now is enough.
Proposals before writes
Catch up and Shift the rest go through Rebalance: nothing moves before Accept plan.
Nothing ends by itself
Focus and the task stay as they are until you act; the app only stops counting at 0.
One rule for “now”
Now, Next up, Nothing else today: the same on the Now view, widgets and the Mac menu bar.
Same everywhere (R-13)
iPhone, Android, iPad, Mac and web show the same states.

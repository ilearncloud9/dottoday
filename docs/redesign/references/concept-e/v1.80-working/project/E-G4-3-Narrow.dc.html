Narrow Mac · approved (ED-169, ED-170)
Window: minimum 840 × 640, opens at 1280 × 800, expanded from 840, editor floats below 1160, H1 unreachable. Mac sidebar, menus, shortcuts and the warm vibrancy unchanged.
Day-column fold (computed): fold when the window is narrower than sidebar 200 + Now minimum + Day column 290 + dividers and margins. Now minimum = the measured action row plus padding (550 at 100 % text), giving ≈ 1042. At larger text the fold point is recomputed from the real content (≈ 1500 at 200 % is an estimate, not a constant).
Folded: a 44 px edge button labelled "Day" (aria-expanded, aria-controls, tooltip). It opens the same Day column as a panel over Now, not modal and not dimmed. Esc, ✕ or the button closes it, and focus returns to the button. One Day column only; resizing never saves, discards or changes the date, task, view, focus or scroll.
Shortcuts unchanged: ⌘1 Now · ⌘2 Inbox · ⌘3 Calendar · ⌘4 Search · ⌘K Search or run (the palette). The Day button has no shortcut of its own; View › Show Day Column remains the menu command (its key is shown inconsistently on the boards as ⌥⌘D and ⌥⌘I; see CR-143).
Narrow toolbar (below ≈ 1000): the "Now 10:42 · Wind Down" text is hidden (the Now header shows it); "Search or run" collapses to an icon with a tooltip and keeps ⌘K. The Search screen stays ⌘4 in the sidebar; the two are not merged.
Short windows (under 720 tall): the now-dot draws at ≈ 72 % and the Now pane scrolls. Above 130 % text the dot keeps full size and its numeral does not grow; text wraps and the pane scrolls instead.
C1 (a): the Workspace inspector (248) and the full task editor (420) are different surfaces. The inspector docks from 1160 when the week grid keeps ≥ 3 usable days (3 × 144 + 44 gutter = 476) and everything fits; otherwise it floats. The 1280 Workspace is unchanged.
Real E-Minimal and E-FullA-v2 Mac windows resized, drawn at 50 %. Physical device, VoiceOver, keyboard order and resizing with unsaved edits: PENDING.

Rules
Yours, free, always (R-11)
Export JSON, CSV and .ics on every platform, with or without an account. Import from JSON. Never behind a plan.
Nothing is lost
Every import or restore takes a backup first; a replace moves what is newer to Trash; Undo goes back. Start fresh keeps the old file aside.
Calm words, no red
Replace and Restore are not destructive red: they never delete. Refusals say “Nothing was changed.”
Encrypted by default
Local backups are encrypted with the database key, on this device only. Export files are plain, and the page says so.
System chrome is the system’s
Share sheets, save dialogs, file pickers and downloads are each platform’s own. Dottoday builds the file and hands it over.
Text from the app
Every string on this board is built (app_en.arb). The backup dates and the kept path are examples. No new copy is proposed.

The Earlier rule
Rule (ED-164). Done tasks whose time is before now fold into one collapsible group, labelled only "Earlier". No count, no "3 done", no number anywhere in the row.
Only done tasks fold. Open, current and upcoming tasks always stay on the thread, even when their time has passed. No done tasks before now: no Earlier row.
Expanded rows keep title, time, icon, colour, done appearance and every task action. Reopening returns the task to its time-ordered place.
Folding is presentation only. Stored times, order and completion data never change because of it.
Expanded or collapsed is remembered for the day while the app is open; changing the date starts collapsed. Expanding never changes the selected date or current task.
Where: Minimal Today on phones, the Minimal Day column on Mac and web, and the Full Mac/web Day column. Full phone threads and other Full screens keep done tasks in place and keep their approved counts.
iPad and Android tablets: Prompt D Round 2 decides the layout; the rule above applies unchanged.
Design requirement, not yet built or tested in the app.

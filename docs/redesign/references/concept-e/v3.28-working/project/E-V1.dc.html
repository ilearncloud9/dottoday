How it fits approved Concept E behaviour

  • Matches ED-099 (G2-12 A): one Day review body (done count, Move the rest to tomorrow?, sleep line); on minimal Mac and web it opens in the Day column like a task (ED-089); ✕ or Esc returns to the Day; the main pane stays on Now.

  • One mismatch: the drawing has a “Week in review” row. ED-093 keeps Week in Review in Full and ⌘K for minimal Mac and web, and ED-099 hides it on minimal phones (doc 14 hides the weekly prompt in minimal). The row is the only part that disagrees.
  • Proposed correction: remove that one row; nothing else changes. Week in Review stays reachable from ⌘K and Full. This is a correction, not a new design.
  • Platform note: one drawing stands for Mac and web here; small text uses the system font on each (SF Pro on Mac, the browser's system UI font on web).

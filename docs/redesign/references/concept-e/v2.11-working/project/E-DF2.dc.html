Before Wake Up and after Wind Down · the rule (built, docs/02 F1.15)
  • Tasks that end by Wake Up fold into one row above the sun cap; tasks that start at Wind Down or later fold into one row below the moon cap. Tap (or Return) unfolds them into ordinary rows: open, done, drag, select.
  • Full shows the built wording “1 task before Wake Up” / “2 tasks after Wind Down”. Minimal says “Before Wake Up” / “After Wind Down” with no count (doc 14 rule 5, as the Earlier fold, ED-164).
  • A task that crosses a cap stays inline: Morning run 6:45–7:30 AM is drawn correctly today.
  • A zone that holds the live task starts unfolded; the Week board shows every task.
  • The horizon spans Wake Up to Wind Down. A crossing task starts at the edge (Morning run at 7 AM). Tasks wholly outside are not drawn on it; its spoken summary names them (“Before Wake Up: Early run, done”).
  • Mac and web Day column: the same row above the sun cap, keyboard focusable, Space or Return toggles.

The moving now · the rule (extends the built minute tick, docs/03 §3.1)
  • The now-bead and its pill move once a minute, on the minute (built minuteTick). The pill shows the new minute at once; the bead slides the one-minute distance in 200 ms ease-out (DotMotion.base). The teal elapsed thread grows with it.
  • Reduce Motion: the bead jumps (DotMotion.reduced, built: every duration zero). Nothing pulses or ticks.
  • Back from the background: the bead is drawn at the current time at once; it never animates the missed minutes.
  • Screen readers: the bead is labelled “Now, 10:42” and updates silently each minute (no announcement every minute). One polite announcement when the current task changes, e.g. “Now: Lunch, until 1:15 PM”; focus never moves.
  • Same rule for the horizon bead and the Mac/web Day column bead (14 px).

Rules
One row, same everywhere
The Earlier fold component: one quiet row, the task’s colour, Show or Hide. Phones, Mac and web.
Full counts, Minimal does not
Full: “1 task before Wake Up” / “2 tasks after Wind Down” (built). Minimal: “Before Wake Up” / “After Wind Down”.
The live task never hides
A zone with the live task opens by itself; one picked by multi-select or the keyboard opens too (built reveal).

What exists and what is still a choice

  • Built (doc 14 §3, task_sheet.dart): minimal sheet = title, time and length, Done · Tomorrow · Later · Delete; everything else under More options (the full editor).
  • E-PhonesMinimal: no task sheet drawn (its band only says Move lives on the task sheet).
  • E-Minimal (1): Starts, Duration, Tomorrow · Later · Move…, More details; no Done, no Delete; Tomorrow offered for the task running now.
  • G2-5 option D (approved): More options opens the option D full editor in every mode (minimal hides, never removes).

Options

A (recommended). The built set on every platform, in option D's look (2–5): Done · Tomorrow · Later · Delete; time and length shown; More options → the full editor. The running task also shows Need more time? (3), because that is minimal's own Now action. The dot is not a colour and icon button in Minimal (colour and icon live under More, doc 14).
B. E-Minimal's set as drawn (1): no Done or Delete on the screen; Move… as a third button.
C. A plus Move… as a fifth action (tiles wrap to 3 + 2).

Why A

It is what the app does today and what doc 14 adopted (ED-068 changed only navigation). Done stays one tap away (doc 14 rule 2); Delete keeps one rule everywhere (Trash + Undo); Move stays one step away under More and as Tomorrow/Later shortcuts. Choosing A changes E-Minimal's task screen (1 → 5): shown first for your review, as before.
